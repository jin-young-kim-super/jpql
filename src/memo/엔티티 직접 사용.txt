ex)
select count(m.id) from Member as m : m이라는 엔티티의 id를 사용
select count(m) from Member as m : m이라는 엔티티 직접 사용
-> 순수 SQL에서는 예를 들어 함수의 파라미터로 어떤 특정한 값을 보통 넘긴다. 그러나 JPQL은 객체 쿼리문이기에 위 예시처럼 엔티티(m)을 직접 사용하는 것이 가능하다. 

Q. 그럼 count(m)으로 엔티티를 직접 사용했을 떄 SQL은 어떻게 변환이 되냐?
A. JPA에서는 엔티티를 직접 사용 시, 엔티티를 식별할 수 있는 게 기본키 값이니, 기본키 값(PK)으로 자동 변환이 된다. 엔티티를 식별할 수 있는 기본키 값(PK)를 사용하지 않게 되면
count(m)을 통해 엔티티의 정확한 개수 계산을 할 수가 없다. 


[SQL]
select count(m.id) from Member as m
-> 마치 자바에서 System.out.println(Member) 처럼 객체를 직접 사용 시 자동으로 toString()이 호출되는 것과 비슷한 원리이다. 

엔티티를 파라미터 바인딩해도 기본키 값으로 변환
ex)
String jpql  = "select m from Member m where m = :member";
List resultLIst - em.createQuery(jpql)
		.setParameter("member", member)
		.getResultlList();
[SQL]
select m.* from Member as m where 【m.id】 = ?;


엔티티 직접 사용 : 외래 키(FK) 변환
-> JPQL에서 [연관 관계]인 엔티티를 직접 사용하게 되면 기본키(PK)가 아닌 외래키(FK)로 SQL로 변환
ex)
String jpql  = "select m from Member m where [m.team] = :team";
List resultLIst = em.createQuery(jpql)
		.setParameter("team", team)
		.getResultlList();
[SQL]
select m.* from Member m where [m.team_id] = ?;
