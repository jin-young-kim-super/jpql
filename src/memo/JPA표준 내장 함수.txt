Q. 만약 DB에 정의한 사용자 정의 함수를 사용하고 싶을 떄는? JPA 입장에서는 DB에 어떤 사용자 함수가 정의돼 있는 지 모르지 않나?
※실무에서는 JPA 내장 함수 외에 사용자 정의 함수 사용할 일이 너무 많다. JPA 내장 함수는 위 함수들이 전부라서 너무 적다.
A. 사용하는 DB의 방언 클래스를 상속받고, 사용자 정의 함수를 그 클래스에 등록해서 사용 가능

ex) DB의 사용자 정의 등록 방법

// extends PostgreSQLDialect : JPA가 JPQL로 사용자 정의 함수문을 SQL로 변환할 때 어떤 DB의 SQL로 변환해야 하는 지 알려주기 위함
public class MyPostgreSQLDialect extends PostgreSQLDialect {
    public MyPostgreSQLDialect() {
        super();
        // 사용자 정의 함수 등록
        registerFunction("custom_concat",new StandardSQLFunction("custom_concat", StandardBasicTypes.STRING));
    }
}

ex) JPQL에서 DB의 사용자 정의 함수 호출 방법
select 【function('custom_concat, i.name)】 from Item as i

사용자 정의 실행 흐름도
                 Hibernate
                     │
                     ▼
          PostgreSQLDialect
                     │
              ← 상속(extends)
                     │
                     ▼
       MyPostgreSQLDialect
                     │
            custom_concat 등록
                     │
                     ▼
JPQL: function('custom_concat', i.name)
                     │
                     ▼
              SQL 생성
